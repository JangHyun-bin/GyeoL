## Findings Fixed

1. Public-site mobile preview could appear clipped in Chrome headless captures.
   - Fix: tightened mobile preview width, overflow, and internal card wrapping in `styles.css`.
   - Verification: CDP layout metrics after the fix report `scrollWidth == clientWidth`.

2. Document demo pages rendered flush to the browser edge.
   - Fix: added `@media screen` body padding to print-oriented document templates so browser preview has page margins without changing print `@page` margins.
   - Verification: recaptured `demo-one-pager.png` and `demo-long-doc.png`.

3. Landing-page demo header CTA used default blue underlined link styling.
   - Fix: styled the header link as a restrained pill action in both landing-page templates.
   - Verification: recaptured `demo-landing-page.png`.
