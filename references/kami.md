# Kami Reference

Gyeol credits Kami as its main structural reference.

Kami influenced these choices:

- A skill-first repository with `SKILL.md` as the agent entry point.
- Self-contained templates under `assets/templates/`.
- Reference documents for design, writing, production, and verification.
- A single template registry that build scripts can check.
- Fast local checks before slower render verification.

Gyeol changes the product direction:

- Korean and English are the first-class language pair.
- Templates are rewritten for native Korean/English business writing.
- The visual system is sans-first and enterprise-oriented.
- Kami's warm parchment identity is not reused as Gyeol's default tone.

Gyeol should keep this attribution visible in README, CREDITS, NOTICE, and this reference.
