# Brand Notes

Use this file as a starting point for `~/.config/gyeol/brand.md`.

## Identity

Gyeol Studio builds practical tools for teams that need polished Korean and English business documents from agent workflows.

## Voice

- Prefer short Korean headings.
- Use direct verbs and concrete nouns.
- Avoid inflated startup language.
- Keep English concise and specific.

## Defaults

- Use Korean when the request is ambiguous.
- Use English when the source material is already English and the user does not ask for translation.
- Use the brand color as an accent only when it remains readable and restrained.

## Reusable Proof Points

- Verified bilingual template stack.
- Structural checks through `python scripts/build.py --check`.
- Browser/render QA notes in `docs/design-qa/`.
